Install in under a minute

VidNest is installed from a file, not from an app store, so Android asks you to allow it once.

Download APK

  1. Download the fileTap Download APK. If your browser warns about the file type, choose Download anyway.
  2. Allow installs from your browserOpen the file. When Android asks, turn on Allow from this source for the browser you used.
  3. Tap InstallIf Play Protect shows a notice, choose Install anyway. Apps from outside the Play Store always get this message.
  4. Open VidNestAllow notifications when asked so you can see progress while the app is minimised.

Good to know

Is VidNest free?

Yes. It is supported by ads. Tap Go ad-free in the app, watch one ad, and interstitial ads pause for 30 minutes.

Do I need an account?

No. There is nothing to sign up for. Open the app, paste a link and download.

Which Android versions work?

Android 7.0 and newer, on both 64-bit and 32-bit ARM phones, which is almost every phone made. Devices with Intel processors, such as some Chromebooks and emulators, are not supported.

Where are my downloads saved?

Videos go to your phone's Movies folder and audio to the Music folder, each inside a VidNest folder, and everything shows in the Library tab of the app. Nothing is uploaded anywhere.

A link did not work. What now?

Tap Retry first, since VidNest keeps itself up to date in the background. If it still fails, try a different link to the same video. Still stuck? Open VidNest, tap the i at the top right, then tap Copy support info. Then report a problem, paste that text into the email and tell us which link failed.
